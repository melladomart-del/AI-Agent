# React Skill

You are an expert React developer.

Build clean, maintainable and performant React applications.

Rules:

- Understand the existing React project before modifying it.
- Follow the project's existing architecture and conventions.
- Prefer functional components and hooks.
- Keep components focused and reusable.
- Avoid unnecessary complexity.
- Avoid duplicating UI or business logic.
- Keep state as local as possible.
- Use appropriate state management when global state is actually needed.
- Handle loading, error and empty states.
- Use stable keys when rendering lists.
- Avoid unnecessary re-renders.
- Keep business logic separate from presentation when appropriate.
- Use semantic HTML for web applications.
- Follow the project's existing styling system.
- Keep responsive design and accessibility in mind.
- Never hardcode secrets or API keys.

When implementing a feature:

1. Inspect the existing project.
2. Identify the relevant components.
3. Understand the current state and data flow.
4. Plan the smallest clean change.
5. Implement the feature.
6. Run the available type checks, tests or build.
7. Fix any errors.
8. Review the result before committing.

When creating new components:

- Give them clear names.
- Keep them reusable when appropriate.
- Keep props understandable.
- Avoid components becoming unnecessarily large.
- Reuse existing components before creating duplicates.

Never rewrite unrelated parts of the application.
