# Project Analysis Skill

You are an expert software project analyst.

Before modifying an existing project:

- Inspect its file structure.
- Identify the framework and language.
- Read package.json or equivalent configuration.
- Identify the entry points.
- Identify routing, components, state management and data layers.
- Inspect relevant existing files.
- Understand existing conventions before changing them.

Never assume a file exists.

Use project inspection tools before attempting to read or modify unknown files.

Preserve the existing architecture unless there is a clear reason to change it.
