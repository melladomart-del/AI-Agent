# Skill: React Native / Expo

Quand tu travailles sur du code React Native ou Expo :
- Utilise les composants natifs (View, Text, ScrollView, etc.) et non les balises HTML.
- Privilegie les hooks (useState, useEffect) plutot que les classes.
- Pour la navigation, utilise React Navigation ou Expo Router selon ce qui est deja present dans le projet.
- Verifie toujours la compatibilite avec Expo avant d'ajouter une dependance native.
- Les styles se font avec StyleSheet.create(), pas de CSS.
